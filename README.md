# Royal-Red-Sandal-Farming
Royal Red Sandal Farming – A website sharing red sandalwood cultivation information, farmland project details, investment plans, plantation photos, legal guidance, and contact information.
ROYAL RED SANDAL FARMING WEBSITE STARTER

Files:
- index.html: responsive one-page website
- assets/: uploaded reference posters and Instagram QR image where available

Preview:
1. Extract the ZIP.
2. Double-click index.html to open it in your browser.
3. The website works locally. Some photos are local assets, so keep the assets folder next to index.html.

Publish free with GitHub Pages:
1. Create/sign in to a GitHub account at https://github.com/
2. Create a public repository named royal-red-sandal-farming (or USERNAME.github.io for a user site).
3. Upload index.html and the complete assets folder.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; choose main and /(root); Save.
6. Wait for publishing, then use the URL shown in Settings > Pages.

Before publishing:
- Verify the business's legal name, ownership claims, certificates, current prices, project locations, permissions, facilities, and all investment/return claims.
- The investment table is a sample based on user-supplied promotional material and is not verified.
- Update WhatsApp number/email only if these are the correct business contact details.
- The enquiry form opens WhatsApp with a prefilled message; it does not save enquiries to a database.
- Keep your contact details and public website files free of sensitive information.
